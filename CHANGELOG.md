# Changelog

## 0.1.0 - 2026-10-20

First public release.

- launchd-run JXA daemon (`daemon.js`) with file-based request/response protocol.
- Verbs: `run`, `applescript`, `jxa`, `screenshot`, `ping`, Chrome tab verbs.
- Python/CLI client `mac_proxy.py`; `vol_io.py` fallback helpers for external drives.
- `install.sh` for install and update; 15 tests.
